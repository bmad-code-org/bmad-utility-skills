# Experiments

Skill experiments moved from the retired OSS teamspace repo. They are not installable: neither the plugin (which reads `skills/`) nor `npx skills add` (which looks one level deep at the repo root) picks them up. To try one, copy its folder into your own skills directory. To ship one, move it into `skills/`.

- `av-good-ideas-mode/`
- `av-human-review/`
